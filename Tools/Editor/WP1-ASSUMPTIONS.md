# WP1 assumptions

These are the places the capture rig can disagree with a headset or with a later visual pass. They are not measured results.

- Seated eye height is the XR rig floor plus 1.2 m. Standing eye height is that same floor plus 1.6 m. The XRI prefab's Camera Offset (about 1.36 m) is not the standing view. The capture copies the rig camera's field of view, near clip, far clip, clear flags, and culling mask. That lens is not a Quest 2 lens model.
- V5 pitches up 35 degrees from the horizontal gaze. V6 stands 0.6 m from the console-bounds center toward the seated eye. V3 and V4 stand just inside the nearest `Bulkhead_Port*` or `Bulkhead_Starboard*` module, cleared by half that module's larger horizontal scale plus four near-clip distances. V7 backs off the window by the distance that fits the window height in the capture field of view.
- `ConsoleBounds` is the world bounds of enabled renderers under `TactileEngineeringWorkstation`, excluding `BridgeChair_*` and particle renderers. Its empty transform stores that box as position, identity rotation, and scale. `WindowBounds` copies `PanoramicViewportGlass`. Corner projection uses `Camera.WorldToScreenPoint` and drops corners behind the camera, so a box that crosses the near plane can project short.
- The squint image is a 16-by-9 grid of block averages, scaled back up by repeating each block. It is not a filter of 16-by-9-pixel tiles. `clippedCenterExclWindowPct` counts every pixel that is not inside the window rectangle.
- Crisis is the opening preset (`BrokenConfig_Opening` when `LevelResetter` has it) with no `TriggerForwardPass`. Success is w1=1, w2=1, bias=-0.5, Step, both cables connected, and `TriggerForwardPass` must return `Passed`. Fail is weights 0, 0, bias -0.5, Step, both cables connected, and `TriggerForwardPass` must return not `Passed`. Each state resets first, because a passed evaluation does not clear `HasSolved` on its own. Existing presentation may still not show a distinct fail color. The file names mean the evaluation state, not a color grade.
- The capture camera stays disabled and is submitted with `UniversalRenderPipeline.SingleCameraRequest`. `RenderSingleCameraInternal` in this URP package does not check `Camera.enabled` in the section that was read. A black capture would mean that assumption is wrong.
- `UnityStats.triangles` and `UnityStats.drawCalls` are the editor Stats counters during Play Mode, not a Quest 2 profile.
- `DevHeadsetTextStrip` is scene content created by the editor builder. `Tools/Editor` does not compile into player builds, so a release build of the generated scene still contains the strip until a later package removes it. It is not `AuraSubtitles` or the world-space HUD. Letter height is the TextMeshPro text bounds (ascender to descender) after scaling to `distance * tan(angle)`. A human has to read it and write the angle into the task file. No angle result is recorded here.
