# Task: Phase 0 — Replace the fake rig with the XRI Starter Assets rig

Status: in-progress (awaiting Link playtest)
Owner: XR / Tools/Editor (scene builder)
Created: 2026-09-29
Updated: 2026-09-29

## Description

Playtests over Quest Link showed the view snapping back to a fixed pose, locomotion passing through walls, and the right controller unable to point. Root cause: the scene has no real XR rig (`XR Origin (VR Rig)` is an empty Transform; no `TrackedPoseDriver`, `CharacterController`, XRI interactors, `InputActionManager` or `XRInteractionManager`), and interaction runs through custom `MonoBehaviour` raycasts. This task implements ADR-007: instantiate the XRI 3.6 Starter Assets rig in the Level 01 scene, retire the custom pointer and desktop camera override, convert first-party interactables to XRI, replace the `OnGUI` HUD with world-space UI, and enable the Android OpenXR loader for Quest builds.

Decision record: [`ADR-007-xri-starter-rig.md`](../../Documentation/Architecture/ADRs/ADR-007-xri-starter-rig.md). Tooling: [`ADR-009-unity-mcp-tooling.md`](../../Documentation/Architecture/ADRs/ADR-009-unity-mcp-tooling.md).
